# All Commands

An exhaustive list of all the commands offered by Pixtoka arranged in categories.
The usage of each commands is explained in details in the command's page.

## General

| Command | Description | Usage |
| :--- | :--- | :--- |
| [`/help`](/commands/help) | Display informations about a command | `/help [(command)]` |
| [`/ping`](/commands/ping) | Display bot's latency | `/ping` |

## Moderation

| Command | Description | Usage |
| :--- | :--- | :--- |
| [`/ban`](/commands/ban) | Ban a specified user (no access) | `/ban [@user] [reason] [(time)]` |
| [`/mute`](/commands/mute) [`/timeout`](/commands/timeout) | Mute a specified user (read-only) | `/mute [@user] [reason] [(time)]` |
