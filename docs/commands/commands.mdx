# All Commands

An exhaustive list of all the commands offered by Pixtoka arranged in categories.
The usage of each commands is explained in details in the command's page.
Some commands may have multiple way of being called, they are called "alias".

## General

| Command | Description | Usage | Alias |
| :--- | :--- | :--- | :--- |
| [`/help`](/commands/help) | Show the list of commands or information about one | `/help [(command)]` |
| [`/ping`](/commands/ping) | Show bot latency | `/ping` |

## Moderation
